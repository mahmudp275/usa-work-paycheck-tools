USA Paycheck & Work Tools — WordPress plugin
================================================

INSTALL
1. In WordPress, go to Plugins > Add New Plugin > Upload Plugin.
2. Upload usa-work-paycheck-tools.zip.
3. Activate "USA Paycheck & Work Tools".
4. Create a page named "USA Paycheck & Work Tools".
5. Add a Shortcode block containing:
   [usa_work_tools]
6. Publish the page and preview it on desktop and mobile.

INCLUDED TOOLS
- Hourly to Yearly Salary Calculator
- Overtime Pay Calculator
- Paycheck Take-Home Estimator (user-entered withholding percentage; not state-specific tax software)
- Work Hours & Break Calculator
- SEO-oriented explanatory content and FAQ

SEO SETUP
Suggested SEO title:
USA Paycheck & Work Calculators | Salary, Overtime & Work Hours

Suggested meta description:
Use free USA paycheck and work calculators to estimate hourly-to-yearly salary, overtime pay, take-home pay, and paid work hours. Results are estimates only.

Suggested URL slug:
usa-paycheck-work-calculators

IMPORTANT
- The paycheck tool does NOT calculate real state/federal taxes. Users enter their own combined withholding percentage.
- Review overtime content and tax disclaimer before publishing. Link to official sources such as IRS.gov and DOL.gov.
- Add your own About, Contact, Privacy Policy, Terms, and Disclaimer pages.
- SEO results are not guaranteed. Avoid publishing thin duplicate pages for every state. Add genuinely useful, reviewed state-specific content before targeting state keywords.
